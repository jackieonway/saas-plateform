# SSO 登录保护

账号密码仅提交给认证中心，平台不处理密码登录。认证中心使用受限的密码工作线程、队列、验证期限和登录来源限流；预算饱和与权威不可用均失败关闭。

全局 SSO 会话使用 Secure/HttpOnly Cookie，预认证挑战与 CSRF 绑定。用户名、邮箱和电话等标识的候选核验不能把未验证账号放入成功结果，也不能用候选部分完成的状态签发凭据。

OIDC 客户端使用精确 HTTPS redirect URI、用途与成员类型准入、code + S256、state、nonce 和独立 RS256 签名密钥。平台 BFF 验证发现文档与 issuer，服务端加密保存上游凭据；浏览器只得到最小状态和内存短期 Bearer。

账号禁用、密码变化、全局踢出、成员/组织失效和客户端政策变化通过真实代际与原始来源证明拒绝旧请求。刷新未知结果不能重放旧上游 refresh；注销未知结果必须按既有请求恢复，不删除后来建立的新会话。

认证日志、管理审计和指标不能记录密码、哈希、Cookie、Authorization、token、私钥、完整请求或数据库连接串。当前参数以身份服务和平台 `config` 模块为准；验证需覆盖预算、CSRF、会话代际和并发撤权。
