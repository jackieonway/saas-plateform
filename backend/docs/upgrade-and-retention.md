# 升级、回退与版本保留

平台程序升级、微应用入口切换、静态资源清理和数据库恢复是四类操作。qiankun 统一浏览器运行方式，环境 URL、固定版本、ZIP 与受管镜像仍有各自的交付和保留规则。

## 平台升级

升级前记录当前前后端镜像摘要、私有配置、数据库迁移历史、环境 URL、发布 active/previous 指针和网关路由，验证备份可从远端取回。在隔离环境检查新 API 与当前 schema、宿主和业务 SDK 的兼容性，通过后按[平台部署](deployment.md)更新镜像。

新增迁移通过新文件执行，不重写已应用 SQL 或 checksum。平台启动迁移不是数据库回退工具。旧 API 镜像可能拒绝较新的迁移历史，即使旧查询能读取部分表，也不能推断可以直接回退。需要数据库恢复时使用新的隔离目标，见[恢复指南](../ops/recovery/README.md)。

宿主静态镜像更新也需保留已打开页面的旧 chunk。registry 中保留旧镜像，不等于旧资源 URL 仍在线；实际网关和静态存储必须继续提供它们。

## 微应用入口变更

| 当前入口 | 变更或回退步骤 |
| --- | --- |
| 环境 URL | 保存原地址及代理状态，在对应环境修改 URL，核对新 revision、实际 browserEntryUrl 和资源；恢复时重设原地址 |
| 发布 active 指针 | 登记新不可变版本，执行服务端预检，通过后激活；回滚接口会重新预检 previous 版本 |
| ZIP 节点版本 | 除发布预检外，全部必需节点重新校验文件树与真实静态 URL；节点未就绪阻止切换 |
| 受管镜像版本 | 核对目标策略、镜像摘要、部署任务、就绪回执、真实静态 URL，再切换发布指针 |

环境 URL 优先于该环境发布指针。因此已配置直接 URL 时，仅回滚发布指针可能不会改变用户实际加载入口。切回版本发布前，要明确移除对应环境 URL 配置并验收。环境 URL 是可变配置，不具备旧 revision 的长期资源保留承诺，见[环境 URL](environment-url-entries.md)。

每次变更检查最终 CSP、qiankun 加载/卸载、组织切换、撤权、业务读写、MIME 与缺资源 404。HTML 预检通过不能代替实际浏览器生命周期和业务授权验收。

## 静态产物与清理围栏

固定版本路径 `/sub-apps/<app>/versions/<version>/` 一经发布，应持续对应同一份产物。保留 HTML 及其全部静态依赖，不能只留入口，不能把所有历史前缀指到新容器。

受管镜像按完整版本目录绑定部署与清理门禁。目录入口、`index.html` 和嵌套资源共享就绪状态；移除目标配置不会解除历史回执要求。`CLEANING` 中的目录不能通过改入口文件、登记别名或重试旧部署任务重新安装。

清理失败或远端结果未知时围栏继续有效，查询和处理原任务。原清理任务重试可以排队，但不会提前把产物改回可部署。外部维护不得删未知路由、容器或目录来掩盖所有权冲突。

## 只读保留预览

`GET /api/applications/{id}/releases/retention-preview` 需要具备相应权限的平台根管理上下文。[管理 CLI](../tools/platform-admin/README.md) 对应命令：

```sh
saas-platform-admin retention-preview --app-code work-orders --minimum-age-days 30 --keep-latest 5
```

`minimumAgeDays` 为 30–3650，`keepLatest` 为 5–1000。默认保留 30 天或最近 5 版，两种保护取并集；还保护 active、previous、跨环境引用、共享 URL/摘要、未来时间、外部所有权和在途操作。环境参数不能作为可安全删除的隔离边界。

结果固定声明 `applyAvailable:false`、`deletionPermitted:false`。此预览没有 apply/delete 能力，候选项仅供进一步人工核对。受管镜像的专用清理任务是另一流程，不能将预览输出直接当成删除授权。

## 在途操作与恢复材料

发布操作具有持久保护。结果未知、取消或依赖失败时不能靠 TTL 自动解除；应核对原意图、任务和审计，正常结束只释放自身保护。

审计、通知、业务软删除、会话、幂等 receipt 和提醒 intent 有不同保留约束，不套用静态版本的天数。备份应保存数据库实际引用的全部 URL 版本、ZIP 内容、镜像、SDK 和网关路由；现有 pilot 恢复工具只验证固定材料布局及已收集文件摘要，不能自动证明数据库引用或 HTML 依赖齐全。在线保留不能代替恢复演练和可测量的 RPO/RTO。
