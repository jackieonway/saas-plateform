# 管理审计

平台管理接口对关键身份、组织、授权与发布操作记录受控审计。记录包含操作者、目标、动作、结果、时间及规范化来源，不写入密码、token、secret 或完整远端敏感正文。

## 写入边界

需要强一致审计的本地变更将业务写入与审计放在同一数据库事务；审计失败时不留下部分变更。批量操作需要在当前权限范围内逐项核对，不用一条含糊成功记录代替实际结果。

外部 HTTP、容器或静态节点任务无法与平台数据库组成单一事务。此类操作使用持久任务/意图、attempt/nonce 和真实回执核对，响应丢失时保留未知状态，后续先查询而非自动重复执行。

## 查询与使用

管理接口为 GET /api/audit-logs 和 /api/audit-logs/export，调用者仍受当前角色与组织管理边界约束。客户端仅展示已校验字段，错误不回显服务端敏感文本。

来源身份由可信代理策略统一规范化，见 [登录保护](login-protection.md)。前端重试不能替换后端幂等与版本检查。

审计不是操作授权本身，也不自动赋予删除权限；在线保留与备份恢复分别处理。实际故障、回滚和数据库测试需在隔离环境执行，见 [工程与验证](engineering-baseline.md)。
