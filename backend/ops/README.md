# 平台运维工具

本目录有两个独立 Rust 工程，不参与平台前后端编译，也不准备其他仓库源码。应用部署入口在 backend/compose.yml。

| 工程 | 作用 | 使用入口 |
| --- | --- | --- |
| monitoring | 四服务健康探测、私有指标、备份事件状态 | [监控指南](monitoring/README.md) |
| recovery | 平台、工单、门店三库协调备份和新目标隔离恢复 | [恢复指南](recovery/README.md) |

先独立构建，再配置实际目标、私有凭据和运行环境。没有自动安装的 systemd 服务或定时器；监控外部告警、生产 PITR 未实现。CLI 成功和健康检查通过均不能替代真实业务验收。
